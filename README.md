# ⛳ 골프모아 (GolfMoa) - 골프장 맞춤 선택 & 스펙 비교 포털

골퍼들이 자신의 실력, 취향, 예산, 동반자 구성에 맞춰 가장 최적의 골프장을 손쉽게 찾고 비교할 수 있는 플랫폼입니다.

---

## 🎯 핵심 기능

1. **스마트 다중 필터 & 정렬**
   - **지역별 탭**: 경기남부, 경기북부, 인천, 강원, 충청, 전라, 제주
   - **비용 필터**: 1인 실부담 총비용(그린피 + 카트비 분담 + 캐디피 분담) 상한선 슬라이더
   - **접근성 필터**: 서울(강남) 기준 소요시간 슬라이더 (40분 초근교 ~ 90분 이내 등)
   - **잔디 종류**: 조선잔디(한국잔디) vs 양잔디(켄터키블루/벤트그라스)
   - **플레이 옵션 칩**: 노캐디 가능 구장, 2인 라운드 가능 구장, 야간 3부(초고광량 LED) 구장, 티박스 매트 없는 100% 잔디 구장, 드라이빙 레인지 보유 구장

2. **테마별 맞춤 큐레이션**
   - 🐣 **초보/골린이 추천**: 평지형 링크스 코스 & 넓은 페어웨이로 OB 부담이 적은 구장
   - 🌱 **양잔디 매니아**: 디봇 떼장을 시원하게 파낼 수 있는 켄터키 블루글라스 구장
   - 💰 **노캐디 & 2인 실속 가성비**: 캐디피 0원 또는 2~3인 플레이가 자유로운 구장
   - 🌙 **퇴근길 야간 3부**: 대낮처럼 환한 LED 조명 라이트 맛집
   - 🏆 **상급자 토너먼트 코스**: 그린 스피드 2.9m+ 이상의 익스트림 유리판 그린 코스

3. **1:1 골프장 스펙 비교표 (다나와식)**
   - 최대 3개 구장을 나란히 비교
   - 주중/주말 및 인원수(2인/3인/4인)별 1인 실부담 총비용 자동 계산
   - 잔디, 전장, 페어웨이 폭, 그린스피드, 티박스 컨디션, 부대시설 일대일 대조

4. **1인 총비용 계산기 (Detail Modal)**
   - 주중/주말, 2인/3인/4인, 캐디 동반/노캐디 선택에 따른 1인 부담금 및 팀 전체 총액 실시간 환산

5. **지도 탐색 (Map View)**
   - OpenStreetMap & Leaflet 기반 위치 시각화 및 마커 팝업을 통한 빠른 스펙 확인

---

## 💻 실행 방법

```bash
# 1. 의존성 설치 (최초 1회)
npm install

# 2. 로컬 개발 서버 실행
npm run dev
```

브라우저에서 `http://localhost:5173`으로 접속하여 확인하실 수 있습니다.

---

## 🛠️ 기술 스택
- **Framework**: React 18 + TypeScript + Vite
- **Styling**: Tailwind CSS v4
- **Icons**: Lucide React
- **Map**: Leaflet + React-Leaflet
- **Data Model**: 정형화된 골프장 스펙 스키마 (`src/types/golf.ts`)
